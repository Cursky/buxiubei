## 一、需求复述（AI 理解版本，待客户确认）

客户的核心诉求：**非常高的场景一致性 + 非常高的角色位置/轴线一致性**。为此在提示词层必须落地下列 5 条硬性规则。

### 规则 1 · 所有说话角色必须绑定"确定语音参考"
- 任何一个角色开口说话的地方，都必须在该条对话中**显式标注其语音参考文件**，并附语气。
- 客户示例：
  - `小黑（声音参考 小黑.mp3，语气开心）说：「XXXX」`
- 实际提示词中当前已部分做到（例如 `鲷哥-电竞队服（鲷哥声音，画外语音）说`），但尚未**统一格式**、也**未指向具体文件名**。
- **规则落地形式（Q6 + Q7 客户已答复、已锁死）**：
  - 完整格式：`角色名-形态 [面向 <对象/方向>]（声音参考 <文件名>，语气<语气>）说：「台词」`
  - 画外音变体：`角色名-形态 [面向 <对象/方向>]（声音参考 <文件名>，画外音，语气<语气>）说：「台词」`
  - 覆盖：所有真人选手对话、解说员对话、系统音对话、场馆广播对话、小马-吉祥物 的 UI 转述对话、游戏内英雄-操作者 形态（如 龙骑-小黑）开口时。

### 规则 2 · 现实层场景必须确定"固定 180° 轴线"，并以左/中/右标明位置
- **覆盖范围（Q4 客户已答复）**：
  - **需要锁定轴线的现实层场景（6 个）**：比赛选手席、训练室复盘区、不朽杯采访台、解说员-赛事直播间、深夜电竞房、不朽杯现场。
  - **不锁定轴线的游戏内战场场景**：对战森林、基地场景。游戏场景交由跟拍 / 环绕镜头 / 低角度仰拍等战斗运镜自由处理，不强制左/中/右固定位。
- 一旦轴线确定，**全 EP 内同一现实层场景的每个镜头**必须遵守同一轴线，不得无故换边。
- 在每一个（现实层）镜头的"镜头描述"中必须写明：
  - 每个在场角色/单位/道具的**左 / 中 / 右**位置；
  - 背景要素（主播台、选手座椅、采访台、麦克风、记分牌、展板）的轴线归属。
- 落地形式（暂拟）：
  - 在每个现实层场景**第一次出现**的镜头中补写一个 **「轴线定义」** 段；
  - 每个镜头描述开头用 `左：xxx / 中：xxx / 右：xxx` 明确现场位置 + 背景关键物。

### 规则 3 · 避免会"污染"视频生成模型的词汇，绕开显示屏/视频画面的错画
- 电脑画面、电脑屏幕、视频内容、监视器画面、直播画面、大屏画面等词汇，会让生成模型为了"展示注意力点"而自行脑补违背物理规律的画面（例如"显示屏背面却出现视频画面"）。
- 凡是画面中出现这类物体、且**不需要显示内容**的（例如镜头看到的是显示屏**背面 / 侧面 / 关机黑屏**），**禁止使用**以下污染词：
  - 屏幕、显示屏、显示器、监视器、大屏、直播画面、视频、画面、映出…
- 替代方案（暂拟，等客户确认）：
  - 以物理实体描述：`黑色机箱侧面`、`显示屏外壳背面金属磨砂面`、`关机状态的显示屏（纯黑反光）`；
  - 以光线描述：`从显示屏前方漏出的冷白色环境光`（不描述画面内容）。
- 反例矫正（已在 EP03 里出现，需要改）：
  - V13 镜头3："身后不朽杯赛事 LOGO 背板 + **双屏监视器映出决胜团战金光画面**" —— 若镜头其实是从解说员正面拍、观众看不到屏幕内容，就应改成"身后不朽杯赛事 LOGO 背板"即可；若必须展示画面内容，则需要明确是"正面显示"并用官方 DOTA2 画面风格词替代。

### 规则 4 · 对话必须标注"面朝哪个角色"以增强镜头逻辑
- 根据：
  - 规则 2 的"每个场景固定轴线 + 左/中/右位置"，
  - 以及台词内容语义推导出的"说话对象"，
- 每一句对白都需要**明确说话人正对的方向/对象**，使后续生成模型能稳定出"人物正在对谁说话"的镜头。
- **落地形式（Q6 + Q7 客户已答复、已锁死）**：
  - `角色名-形态 [面向 <对象/方向>]（声音参考 <文件名>，语气<语气>）说：「台词」`
  - 对"在场"的队友：明确具体角色名，如 `[面向 鲷哥-电竞队服]`；
  - 对"不在场"的对象（小黑对着麦克风说话，其实是对全队）：`[面向 麦克风]` 或 `[面向画面正前方]`；
  - 禁用 `[面向 屏幕]`（规则 3 禁用词）——若需指向屏幕方向，改 `[面向 显示屏外壳前方]` 或 `[面向 主播台正前方]`。
- 对"队友通过语音对小黑喊话"的画外音情况（典型：V05 / V06 / V10 等现实层场景）：
  - 鲷哥/超哥的声音是**画外音**，人物不在画面中 —— 仍需标注"面向画外<方向>（xxx-电竞队服 方向）"，方向按其在该场景轴线上的固定位置推定。
  - 对游戏战场镜头（对战森林、基地场景）的画外音：Q4 已答复战场不锁轴线，画外音方向按"画外左方 / 画外右方"定性描述即可，不必追求精确轴线。

### 规则 5 · 避免 UI、系统展示等画面；如有 UI 文字一律用"小马.png"第一人称转述
- 任何画面中不得出现明显的 UI 文字/图标（系统面板文字、任务完成弹窗、比分 HUD、血条 HUD、装备栏 HUD…）。
- 所有**必须传达给观众**的 UI 内容（例如"任务完成"、"系统升级【团队共担】"、"比分 2:2"、"BKB 图标亮着但未按"），都改成**"小马.png"这一素材的第一人称口述转述**。
- 具体形式（暂拟，待客户确认）：
  - 镜头中不出现原本的 UI 画面；
  - 以小马.png 出镜或画外，以**第一人称**说出该 UI 内容，例如：
    - `小马（声音参考 <小马语音文件>，语气<语气>）说：「我看到系统亮起柔和白光，面板写着——团队共担系统已激活」`。
- EP03 中涉及 UI 的镜头清单（需全部按规则 5 改写）：
  - V02 HUD 装备栏/BKB 图标；
  - V06 HUD 比分 1:2 → 2:2；
  - V07 系统面板说话；
  - V11 系统面板亮起柔和白光 + Buff 数值栏；
  - V14 金色系统面板"任务完成"；
  - V16 屏幕上的新闻报道（第一届老头杯冠军 + 新一届不朽杯宣传）；
  - V17 大屏幕"不朽杯"三个金光闪闪的大字。

### Q3 · 小马.png 这个素材的身份与来源

### Q4 · 轴线的粒度

**AI 的具体疑点**：
- EP03 涉及 **8 个子场景**：对战森林、比赛选手席、基地场景、训练室复盘区、不朽杯采访台、解说员-赛事直播间、深夜电竞房、不朽杯现场。
- 方案 A：**每个子场景独立锁一条 180° 轴线**（EP03 共需锁 8 条轴线）。
- 方案 B：全 EP 共用一条抽象的"主角视角轴线"。
- 方案 C：**只锁对话戏子场景**（选手席、训练室、采访台、直播间）的轴线；战场类（对战森林、基地）交给跟拍 / 环绕镜头自由决定。

**AI 建议默认值**：
- 采用 **方案 A**：每个子场景独立锁一条 180° 轴线。
- 在每个子场景**第一次出现**的镜头（V03 选手席、V06 基地、V08 训练室、V13 对战森林 + 解说员直播间、V15 采访台、V16 深夜电竞房、V17 不朽杯现场）前补一段 `【轴线定义】`，明确：
  - 谁固定在左 / 中 / 右；
  - 背景关键物（水晶塔 / 高地 / 选手席 / 解说台 / 麦克风 / 赛事 LOGO 背板）在哪一侧；
  - 镜头默认从"哪一边"拍（A 侧机位 / B 侧机位）。
- 同一子场景后续镜头 100% 遵守该轴线，不换边。
- 跨子场景切换（例如选手席 → 战场）允许换轴线，但在切换点用运镜描述承接。

- 最终需锁定轴线的现实层子场景共 **6 个**：比赛选手席、训练室复盘区、不朽杯采访台、解说员-赛事直播间、深夜电竞房、不朽杯现场。

### Q5 · UI 转述的呈现形式

```

  ↑ 画外音省略面朝方向字段（Q9 客户答复）

【小马-吉祥物（仅 UI 转述镜头出镜）】

  ↑ 小马出镜但无台词气泡、无画面文字（Q10 客户答复）；台词仅通过配音播出

【系统音（非人实体）】
系统音（声音参考 系统音.wav，语气<语气>）说：「台词」
```

**面朝方向 `<对象/方向>` 取值**：
- 具体角色：`面向 鲷哥-电竞队服` / `面向 超哥-电竞队服`
- 轴线方向：`面向画面左方` / `面向画面右方` / `面向画面正前方`
- 物理实体：`面向 麦克风` / `面向 机械键盘` / `面向 主播台正前方`
- 画外对象（画内角色对画外喊话）：`面向画外左方` / `面向画外右方`
- 禁用：`面向 屏幕` / `面向 显示器` 等（属规则 3 禁用词，改成 `面向 机械键盘前方` 或 `面向 主播台正前方`）
