## 六、分类口径说明

1. **纯游戏中**：镜头从头到尾只有游戏角色/场景/HUD，无真人角色面部出现、无真人角色当前讲话；系统音 UI 若仅作 overlay 且无真人镜头，仍视作游戏中（如 EP03-V14）。
2. **纯现实中**：镜头只在席位/训练室/采访台/家中/现场等真人空间，**即使**系统音面板 UI 以 overlay 形式出现，只要主体镜头是真人，仍视作现实中（如 EP02-V08 血红任务卡、EP02-V05 倒计时、EP03-V07 系统转折、EP03-V11 团队共担）。
3. **混合**：单个 V 编号的"镜头 1 / 镜头 2 / 镜头 3"分拍在**两种物理空间**（真人席位 ↔ 游戏战场），或画面虽在单一空间但**叙事轨道含跨层切换**（如 EP03-V02 游戏 HUD 主体 + 画外真人语音；EP02-V13 游戏战场 + 观众席大远景 + 真人独白）。
4. **解说员主播台**：属**现实层**。但当解说员镜头与游戏团战并列时（EP03-V13），整个 V 编号归类为"混合"。
