# 场景表

> **场景来源**: 基于三集剧本实际出现场景重建；当前 `真实素材/` 目录为空，因此本表先作为提示词与分镜的标准场景清单。
> **使用原则**: 严格区分 **游戏外现实空间**、**系统空间**、**游戏内战场空间**。同名“大场景”下允许拆成若干子场景使用。

---

## 现实层 / 线下空间

### 深夜电竞房
- **类型**: 室内 / 现实空间
- **主要出场**: EP01-1, EP01-2
- **核心元素**: 昏暗小房间、电脑屏幕单一主光源、泡面桶、空饮料瓶、零食袋、机械键盘、论坛页面
- **氛围**: 宅、闷、深夜上头、嘴炮亢奋
- **提示词备注**: 适合近景、中近景、屏幕反光、手部键盘特写；可承接破屏金手炫技镜头

### 训练室复盘区
- **类型**: 室内 / 现实空间
- **素材文件**: `角色场景图/训练室复盘区.jpg`
- **主要出场**: EP02-V08/V09/V10/V11/V13、EP03-V08/V09/V10/V11
- **核心元素**: 回放屏幕、白色或偏冷训练灯、电竞桌椅、矿泉水瓶、泡面桶、压抑空气、三人围桌或站立对峙
- **氛围**: 压迫、疲惫、争吵、坦白、和解
- **提示词备注**: 现实戏核心场景；适合对峙正反打、过肩镜头、桌面道具特写、系统面板插入

### 比赛选手席
- **类型**: 室内 / 现实空间 / 赛场内部
- **主要出场**: EP01-4, EP01-5, EP01-6, EP03-3
- **核心元素**: 选手座位、显示器排布、耳机、舞台余光、屏幕爆炸反光、疲惫坐姿
- **氛围**: 失败、窒息、轮回疲惫、赛场余震
- **提示词备注**: 现实与游戏内画面交叉的桥接场景；适合从游戏爆炸切回真人反应

### 不朽杯采访台
- **类型**: 室内 / 现实空间 / 赛后场景
- **素材文件**: `角色场景图/不朽杯采访台.png`
- **主要出场**: EP03-V15
- **核心元素**: 金色纸屑、并肩站立、不朽杯采访台背景板、庆功灯光
- **氛围**: 释然、热闹、轻松、带一点互损喜剧感
- **提示词备注**: 三人穿本体电竞队服（不走冠军披风变体）；可在画面中描述金色披风从肩上滑下作为氛围道具

### 小黑现实中的家（复用 深夜电竞房）
- **类型**: 室内 / 现实空间
- **素材文件**: **复用 `角色场景图/深夜电竞房.jpg`**，白天版通过光线描述（暖橙自然光）切换
- **主要出场**: EP03-V16（醒来）
- **核心元素**: 熟悉房间、白天自然光、门票、电脑桌、梦醒后的安静感
- **提示词备注**: 不单出图；与 深夜电竞房 共用素材，首尾呼应通过色温（冷蓝夜→暖橙日）区分

### 不朽杯现场
- **类型**: 室内 / 现实空间 / 场馆公共区
- **素材文件**: `角色场景图/不朽杯现场.jpg`
- **主要出场**: EP03-V17
- **核心元素**: 人群、展板、欢呼、广播声、举手机拍摄、赛场全景、不朽杯大屏
- **氛围**: 热爱落地、回归真实观赛现场、余韵温暖
- **提示词备注**: 适合尾声拉远，全景收束；一张图覆盖"观众席 + 宣传展板 + 场馆大屏"三个子区域

## 系统空间 / 异常空间

### 时空管理局
- **类型**: 虚拟空间 / 系统空间
- **主要出场**: EP01-3
- **核心元素**: 冷蓝色数据流、透明网格、悬浮碎片、巨大系统面板、白光、审判感
- **氛围**: 冰冷、荒诞、强制命运感
- **提示词备注**: 适合悬浮运镜、环绕、数据瀑布、光链缠绕

### 系统冻结异常场
- **类型**: 游戏内与系统空间重叠的异常状态
- **主要出场**: EP01-8, EP01-9
- **核心元素**: 赛场时间冻结、人物停滞、红色裂纹、系统面板强行弹出、红绿逻辑接管
- **氛围**: 异常、崩坏、规则错位
- **提示词备注**: 适合炫技镜头、碎裂转场、画面冻结后只有UI在动

### 团队共担觉醒场
- **类型**: 现实空间上的系统增幅状态
- **主要出场**: EP03-6
- **核心元素**: 训练室本体 + 柔白系统面板 + 金白光带连接三人
- **氛围**: 被接住、认知转折、命运重连
- **提示词备注**: 属于系统型高潮，不要做成纯玄幻，仍要保留训练室真实质感

## 游戏内战场空间

### 对战河道
- **类型**: 游戏内战场（主要战斗地形）
- **素材文件**: `角色场景图/对战河道.jpg`
- **主要出场**: EP01-V10/V12/V15/V16、EP02-V01/V02/V07/V12/V14/V16/V17、EP03-V01/V02/V03/V13
- **核心元素**: 河道、野区草丛、高地台阶、兵线；所有「对局空间」打斗镜头统一归到此场景
- **提示词备注**: **所有团战 / 野区 / 高地推进 / 肉山坑团战都落在此场景**；肉山坑 = 对战河道（地形）+ 肉山（单位）

### 基地场景
- **类型**: 游戏内战场（基地爆炸 / 遗迹爆炸）
- **素材文件**: `角色场景图/基地场景.jpg`
- **主要出场**: EP01-V07、EP01-V10（蒙太奇末端）、EP03-V06、EP03-V14
- **核心元素**: 主基地水晶塔、卫星小塔、爆炸金橙色光球、光柱冲天
- **提示词备注**: 专用于基地被爆 / 夺冠遗迹爆炸等收束镜头；与 对战河道 分开

### 半决赛舞台·中路二塔攻防区
- **类型**: 游戏内战场 + 舞台投屏
- **主要出场**: EP01-7, EP01-8, EP01-9
- **核心元素**: 中路二塔附近战场、敌方隐刺与白虎先手、救人反打、赛点团战、舞台大屏同步
- **氛围**: 赛点反杀、预判、反转、随后异常冻结
- **提示词备注**: 游戏内战斗与舞台观感双线并行；可在一个clip内做“游戏内主画面 + 场馆反应补镜”

### 决赛现场·肉山坑
- **类型**: 游戏内战场 + 舞台投屏
- **主要出场**: EP02-2, EP03-7
- **核心元素**: 肉山坑、肉山、狭窄入口、绕后站位、十人对峙、关键先手、视野争夺
- **氛围**: 屏息、极限决策、团战爆发
- **提示词备注**: 两次用途不同：EP02 是灾难性原地大跳；EP03 是共担后的完美团战

### 决赛现场·比赛推进区
- **类型**: 游戏内战场
- **主要出场**: EP02-4
- **核心元素**: 红温Buff后的反打推进、连续击杀、节奏扭转
- **氛围**: 不讲道理的爆发、反扑、观众席炸裂
- **提示词备注**: 适合高燃快切，但要保留角色清晰度

### 决赛现场·野区与肉山坑推进区
- **类型**: 游戏内战场
- **主要出场**: EP02-7
- **核心元素**: 兽王战鹰掠过野区、肉山坑边缘、提前照亮敌方动向、连续蹲伏
- **氛围**: 视野压制、战术建立、稳稳把节奏拉回
- **提示词备注**: 核心主体是“鸟”的飞行路径与信息差，不是正面团战乱战

### 决赛现场·野区交叉画面
- **类型**: 游戏内战场
- **主要出场**: EP02-8
- **核心元素**: 带宝石深入敌方野区、埋伏、掉宝石、嘘声、送头后的嘴硬
- **氛围**: 尴尬、危险、荒诞、嘴硬反转
- **提示词备注**: 要突出“主动送上门”的失误感与赛场社死感

### 决赛现场·高地推进区
- **类型**: 游戏内战场 + 舞台投屏
- **主要出场**: EP03-1, EP03-2, EP03-8
- **核心元素**: 高地攻防、BKB关键抉择、不朽盾、集火秒杀、最后遗迹爆炸
- **氛围**: 压迫、崩盘、最终胜利时的释放
- **提示词备注**: 既要能拍“不按BKB被秒”的灾难，也要能拍“遗迹金光炸裂”的终局释放

### 失败轮回蒙太奇场
- **类型**: 多个游戏内战场的抽象组合
- **主要出场**: EP01-5
- **核心元素**: 拉比克偷技能、敌法追残血、超哥被羊秒、基地爆炸、耳机摘下、失败循环
- **氛围**: 疯狂、密集、绝望、机械重复
- **提示词备注**: 允许用炫技式蒙太奇、快切、同动作匹配剪辑
